MIROIR ACADEMIA — Administration

Ton espace de gestion

Connecte-toi pour rédiger, publier et gérer les annonces de Miroir Academia.

Configuration nécessaire

L'espace utilise Supabase pour sécuriser les comptes et enregistrer les articles en ligne. Avant la première connexion, il faut créer le projet Supabase gratuit, ajouter l'URL et la clé publique dans config.js, puis exécuter le fichier supabase_setup.sql dans l'éditeur SQL de Supabase.

Aucun mot de passe n'est préinstallé. Tu créeras ton propre compte administrateur dans Supabase Auth.

Connexion administrateur

Le compte doit d'abord être créé dans Supabase Authentication. L'inscription publique n'est pas activée depuis cette page.
